# ctrl-alt-keith

Small, practical projects for AI workflow reliability, knowledge tooling, and
infrastructure validation.

## Projects

- [AI Workflow Playbook](https://github.com/ctrl-alt-keith/ai-workflow-playbook)
  defines reusable guidance for reliable, human-directed AI work.
- [AI Workflow Enforcement](https://github.com/ctrl-alt-keith/ai-workflow-enforcement)
  provides lightweight tools for drift detection and review handoffs.
- [Knowledge Adapters](https://github.com/ctrl-alt-keith/knowledge-adapters)
  acquires and normalizes external knowledge into local, LLM-ready artifacts.
- [Trusted AI Environment](https://github.com/ctrl-alt-keith/trusted-ai-environment)
  explores public-safe evidence for AI environments.
- [Trusted Network Registry](https://github.com/ctrl-alt-keith/trusted-network-registry)
  publishes a public-safe view of a trusted network registry.
- [Linode Image Lab](https://github.com/ctrl-alt-keith/linode-image-lab)
  validates repeatable image capture and deployment workflows.
- [Linode Backup Lab](https://github.com/ctrl-alt-keith/linode-backup-lab)
  validates backups and snapshots.
